  LIMITATIONS:
  1. Rain class is ~12% of dataset -> model performance is biased toward majority.
  2. next_hour_rainfall is zero ~88% of the time -> regressors learn a near-zero bias.
  3. No temporal lag features used yet (e.g. t-1 humidity). Adding them would improve recall.
  4. Models do not capture long-range monsoon onset patterns.
  5. Feature set limited to current-hour; cloud movement vectors not yet available.

  POSSIBLE IMPROVEMENTS (Phase 3):
  -> Add lag features: precipMM(t-1), humidity(t-1), cloudcover(t-1)
  -> Add rolling stats: 3hr / 6hr mean rainfall, humidity trend
  -> Two-stage model: first classify rain/no-rain, then regress amount
  -> Deep learning: LSTM / GRU for sequence patterns
  -> Integrate satellite cloud imagery for spatial cloud tracking
